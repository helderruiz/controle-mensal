# Controle Mensal - Gestão Financeira

Aplicativo PWA moderno para gestão e controle financeiro pessoal.

## 🚀 Funcionalidades
- **Visão Mensal & Saldo em Tempo Real**: Acompanhamento de entradas, saídas e saldo acumulado.
- **Lançamentos em Qualquer Mês**: Escolha livremente qualquer data/mês (passado ou futuro) para registrar movimentações.
- **Seletor Direto de Mês/Ano**: Navegue instantaneamente para qualquer período.
- **Categorias Personalizadas**: Suporte a categorias customizadas (Gasolina, Farmácia, Saúde, Pets, etc.) salvas automaticamente.
- **Relatórios Financeiros Dinâmicos**: Gráficos por categoria e fluxo de caixa dos últimos meses.
- **Funciona Offline (PWA)**: Aplicativo instalável no celular/desktop.
